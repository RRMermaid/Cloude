# Команда личного бренда

Команда ИИ-помощников в Claude Code: делает распаковку, собирает брендбук и общается
с вами как подчинённые и наставники.

## Кто в команде

**Подчинённые**
- **Ева** — менеджер проекта, ведёт диалог и планёрки
- **Соня** — интервьюер, проводит распаковку
- **Дима** — аналитик аудитории и конкурентов
- **Катя** — копирайтер, голос бренда
- **Ника** — дизайнер, визуальный стиль

**Наставники**
- **Марина** — бренд-стратег
- **Алексей** — бизнес-наставник (продукт, цены, продажи)

## Как пользоваться

Откройте новую сессию Claude Code с этим репозиторием и напишите:

| Команда | Что происходит |
|---|---|
| `/unpack` | Распаковка: интервью по 7 блокам, по одному вопросу. Можно прерываться |
| `/brandbook` | Команда собирает брендбук и даёт ссылку на красивую страницу |
| `/meeting` | Планёрка: что готово, что в работе, какие решения нужны |
| `/mentor` | Разговор с наставниками |

Можно и просто писать обычным текстом: «давай продолжим», «напиши пост», «что дальше?».

## Где результаты

Всё хранится в папке `brand/`: карточка, распаковка, брендбук, журнал встреч.
Фото и примеры, которые хотите показать команде, кладите в `brand/assets/`.
